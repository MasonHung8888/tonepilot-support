開始前檢查

  1. 確認 iPhone 與 SoundTouch 設備連接可互通的同一個區域網路。
  2. 到 iPhone「設定 → 隱私權與安全性 → 本機網路」允許 TonePilot。
  3. 先使用「裝置 → 搜尋 SoundTouch 設備」；找不到時再手動輸入 IP 與連接埠 8090。
  4. 若使用多房間，先分別確認每一台設備都能獨立連線。

使用 Siri 與 Apple 捷徑

TonePilot 提供電源、靜音、音量及音效場景等 App 捷徑。第一次安裝新版後，請先開啟 TonePilot 一次並確認設備可以連線，iOS 才能索引這些動作。

  1. 開啟 Apple「捷徑」App，點選「捷徑」分頁，再選擇「App 捷徑」。
  2. 找到 TonePilot，即可執行「切換電源」、「切換靜音」、「設定音量」或「音效場景」。
  3. 若要語音操作，可對 Siri 說：「用 TonePilot 切換靜音」或「用 TonePilot 設定音響音量」。
  4. 若要放在桌面，長按主畫面加入「捷徑」小工具，再選擇 TonePilot 捷徑。
  5. iOS 18 或更新版本可編輯控制中心、加入「捷徑」控制項，再指定需要的 TonePilot 動作。

捷徑執行時，iPhone 與 SoundTouch 必須位於同一個可連線的區域網路。音量仍受 TonePilot 的一般及夜間安全上限保護；電源屬於切換指令，會在開機與待機之間切換。

常見問題

為什麼自動搜尋不到設備？

請確認本機網路權限、Wi‑Fi 與路由器用戶端隔離設定。部分網路會阻擋 Bonjour 或 SSDP，這時可在 Bose 原廠設定或路由器內查看設備 IP，再使用手動連線。

顯示「The request timed out」怎麼辦？

先確認設備 IP 是否改變，重新搜尋並選擇由 /info 驗證成功的設備。若只有多房間查詢失敗，主要遙控功能不應因此被判定為離線。

為什麼目前播放只顯示 TV？

SoundTouch 的 HDMI／TV 音源通常不會回傳 Netflix 片名或電視節目名稱。TonePilot 會顯示設備真正提供的音源及播放狀態，不會猜測觀看內容。

調整滑桿後數值沒有一致？

App 會把數值對齊設備支援的步進，再重新讀取實際狀態。請等待寫入完成；若設備回傳不同值，可重新整理並附上錯誤畫面回報。

場景可以控制 Netflix App 嗎？

不行。Netflix 場景只會調整 SoundTouch 的音效設定；請先在電視或播放裝置開啟 Netflix，再套用場景。

安全音量能阻止遙控器或電視調高音量嗎？

不能。安全上限只套用於 TonePilot 發出的音量指令，無法攔截實體遙控器、HDMI‑CEC 或其他 App 的操作。

TonePilot 能讓 SoundTouch 支援 Dolby Atmos 嗎？

不能。App 不修改韌體，也不會新增硬體不存在的解碼或高度聲道功能。

相容性與驗證狀態

設備目前狀態
SoundTouch 300低音、高音、中央聲道、後環繞及 Dialog 核心音效已由使用者實機驗證。
SoundTouch 10／20／30、Portable、Wave、SA‑4／SA‑5通用探索與遙控架構可依能力回報啟用；尚未實機驗證完整功能。
CineMate／Lifestyle／其他家庭劇院產品只在設備能通過 SoundTouch API 身分與能力驗證時顯示支援項目；尚未實機驗證。

功能以設備實際回傳為準。不支援或尚未確認安全範圍的寫入功能會隱藏、停用或保持唯讀。
